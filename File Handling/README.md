# File Handling & Exception Handling in Python

This folder contains Python programs focused on working with files and handling runtime errors safely.

## Topics Covered

### 📁 File Handling
- Opening and closing files
- Reading data from text files
- Writing and appending content to files
- Working with different file modes (r, w, a)

### ⚠️ Exception Handling
- try, except blocks
- Handling common errors (ValueError, FileNotFoundError, etc.)
- Using finally for cleanup
- Writing safe and robust programs

These concepts are important for building real-world Python applications that handle data reliably.
