# Object-Oriented Programming (OOP) in Python

This folder contains Python programs demonstrating Object-Oriented Programming concepts.

## Topics Covered
- Classes and Objects
- Constructors (`__init__`)
- Inheritance
- Polymorphism
- Encapsulation
- Practical examples of OOP concepts

## Purpose
Object-Oriented Programming helps in writing structured, reusable, and scalable code. These examples demonstrate how to organize Python code using classes and objects for real-world applications.
